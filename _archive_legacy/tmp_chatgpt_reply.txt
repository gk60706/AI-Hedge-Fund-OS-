一、先看策略本身：迁移到 A 股是否成立？
技术逻辑成立

但需要区分日线、60 分钟、15 分钟三个周期。

这套指标的原始设计是：

VWAP 判断价格相对成交均价的位置。

高周期 Supertrend 判断趋势方向。

低周期寻找入场机会。

成交量确认突破有效性。

K 线实体过滤弱突破。

每日最多 3 次信号，限制过度交易。

原始 GitHub 项目：VwapSupertrend-mtf-indicator。

不过，我不建议直接将其 1、3、5 分钟参数平移到 A 股。A 股的交易制度、日内成交结构和价格限制会改变信号的统计特征。

1.1 三个周期怎么使用？

日线：判断中短期趋势

优先实现

VWAP：采用滚动成交额 / 成交量均价，或者用日线成交额 / 成交量计算日成交均价。

Supertrend：ATR(10)，乘数 3。

成交量：20 日均量。

实体强度：大于等于 50%。

用途：全市场候选股过滤。

60 分钟：判断波段趋势

优先实现

Supertrend：ATR(10)，乘数 3。

VWAP：交易日内累计 VWAP。

成交量：同一时段历史 20 日均量。

实体强度：大于等于 50%。

用途：过滤日线选出的弱势股票，识别趋势是否延续。

15 分钟：观察短线触发

第二阶段

Supertrend：ATR(10)，乘数 2.5。

VWAP：当日累计 VWAP。

成交量：同时间段均量比较。

实体强度：大于等于 50%。

用途：给候选股生成短线观察信号，不直接等同于买入指令。

我会采用这样的层级：

日线趋势过滤

60 分钟趋势确认

15 分钟突破触发

生成候选信号

观察 / 等待确认 / 信号失效

这里有个重要区别：

日线负责方向，60 分钟负责趋势确认，15 分钟负责触发。

不要把三个周期的 Supertrend 简单做成三个独立的买入条件，否则会产生严重的信号重复和滞后。

1.2 A 股交易制度带来的失真

A股特征

	

对原策略的影响

	

应对方式




T+1

	

当天买入不能当天卖出

	

信号必须加入隔夜风险




涨跌停

	

突破后无法成交或无法退出

	

涨停、跌停状态单独处理




集合竞价

	

开盘价格可能与前收盘差距很大

	

不把竞价成交量混入正常日内 VWAP




午间休市

	

日内累计指标不能跨午休错误计算

	

上午、下午交易时段统一归属同一交易日




开盘放量

	

开盘前几根 K 线容易异常放量

	

同时段历史成交量比较




尾盘放量

	

收盘前信号可能具有特殊含义

	

单独记录尾盘信号




ST、北交所、科创板

	

涨跌幅限制不同

	

动态读取证券当日涨跌幅限制




停牌及复牌

	

Supertrend 和 ATR 可能失真

	

缺失交易时段不补造价格波动

其中最需要注意的是三个问题。

第一，T+1。

这个指标每天最多 3 次信号，不代表每天最多交易 3 次就安全。

假设 14:45 出现突破信号，收盘前买入，次日低开甚至跌停，原策略并没有解决退出问题。

因此必须加入隔夜跳空风险评估，不能把日内指标的胜率直接当成 A 股策略胜率。

第二，涨跌停。

假设某股票已经封涨停，VWAP、Supertrend 和成交量全部满足条件。

指标可能产生一个完美的突破信号，但实际无法买入。

回测如果按信号收盘价成交，就会虚增收益。

至少应当区分：

涨停且无法成交：不允许买入成交。

涨停打开：记录开板时间和可成交状态。

跌停无法卖出：延迟退出，计入真实风险。

第三，集合竞价。

9:15—9:25 的集合竞价成交不能与连续竞价简单混为一谈。

建议日内 VWAP 从 9:30 开始累计，午休不重置，下午继续累计。

9:25 的开盘价可以作为独立的跳空特征。

2.2 每日 3 次限制不是全市场 3 次

原始 Pine Script 使用的是每个图表实例自己的 session_signal_count。

这意味着：

600519 图表最多 3 次。

300750 图表也最多 3 次。

并不是全市场总共最多 3 次。

而且原始代码的趋势状态并不是每天自动重置，只有价格回到 VWAP 中性位置才会改变状态。这个细节可能导致跨交易日的重复信号抑制。

所以我建议你重新设计，而不是照搬计数器。

暂缓

目的：经过样本外验证后，再研究交易时点。

我不建议现在做自动买卖信号。

原因很简单：你目前的系统主要解决行情和选股，而不是完整的交易执行、成交模拟和风险管理。

先让它成为优秀的研究过滤器，比过早变成交易机器人更稳妥。

4.5 完整信号逻辑

我建议采用以下逻辑：

多头观察信号：

日线 Supertrend 为多头。

60 分钟 Supertrend 为多头。

价格位于对应 VWAP 上方。

当前周期放量。

K 线实体比例大于等于 50%。

收盘价突破前一交易日或近期关键高点。

非涨停无法成交状态。

证券正常交易。

其中突破条件是我建议新增的，不是原始指标的必要条件。

伪代码：

Python
运行
def bullish_signal(x):
    return all([
        x.daily_st_up,
        x.h60_st_up,
        x.close > x.vwap,
        x.rvol >= 1.2,
        x.body_ratio >= 0.5,
        x.close > x.open,
        x.close > x.breakout_level,
        x.tradable,
        x.bar_confirmed,
    ])

这里的 vwap 要根据周期选择对应的日线滚动 VWAP 或盘中 VWAP。
