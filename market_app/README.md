# A股趋势工作台 v1.2.0

一个不商用、只自用的本地 A 股行情与趋势工具。不接实盘交易，不生成买卖建议，也不让大模型自由写报告。

## 直接用打包版

1. 解压 `A股趋势工作台_v1.2.0.zip`（或直接使用 `dist\AStockWorkbench` 文件夹）。
2. 双击 `AStockWorkbench.exe`，会打开独立桌面窗口；不需要浏览器，也不需要 Python。
3. 自选、缓存、信号台账和日志都在 exe 同级的 `market_data` 与 `astock_workbench.log`，整个文件夹可以整体拷走。
4. 首次打开会自动加载贵州茅台的日线趋势；搜索框输入代码或名称即可切换标的。

> 必须保留 exe 同级的 `_internal` 文件夹，不能只单独拷贝 exe。

## 能做什么

- **市场总览**：上证、深证、创业板、科创50 的实时快照；自选行情；涨跌幅、成交额、换手率、数据时间。
- **个股趋势**：日/周/月前复权 K 线，MA5/10/20/60/120、MACD、RSI、KDJ、BOLL、ATR、量比、20/60/120 日涨幅，叠加 VWAP20 和 Supertrend。
- **信号质量灯组**：日线 Supertrend、周线 Supertrend、20 日 VWAP、量比（前 20 日均量，不含当日）、K 线实体占比。v1.2.0 默认核心模式只用日线 + 周线 + 可交易性做硬过滤，其余三盏为观察灯；可切回严格四灯。输出 A/B/C/D 质量分和“新信号/持续合格/未触发/冷却”状态。
- **条件选股**：沪深300、中证500、宽基池、自选池、自定义代码；11 个条件任意组合；可开质量过滤、严格四灯、每日 Top K、同票冷却。
- **今日候选 Top K**：按新信号优先、质量分、命中数、趋势分排序；顶部卡片显示 VWAP 偏离、量比、实体占比和灯组结果。
- **信号台账**：每次带 Top K 的选股完成后，把当日快照写入本地 SQLite 台账；同一天同一只票只记一次，选股页可直接查看近 30 天记录。
- **数据与来源**：分别检测腾讯实时、腾讯日 K、BaoStock，显示延迟、许可、异常原因，不用“看起来可用”代替检测；东方财富和同花顺只保留为备用线索，不参与主流程。

## 回测验收（v1.2.0 进度）

v1.2.0 先做“策略可信度增强”，不是加新因子。

- **P0-1 成本与成交约束：已完成代码与验证。** t 日收盘出信号，t+1 开盘成交；一字涨停买不到、跌停卖不掉顺延、停牌顺延；佣金万 2.5（最低 5 元）、印花税卖出 0.05%、过户费 0.001% 双边、滑点单边 0.1%。
- **P0-1 当前结果：未过验收线。** 300 只当前沪深300成分、320 根缓存（约 1.3 年）的成本后回测：
  - 旧严格五灯：P0 净 PF 0.991、净平均单笔 -0.033%、净超额 +0.428%、t 1.105。
  - v1.2.0 核心模式（日线 + 周线 + 可交易）：净 PF 1.125、净平均单笔 +0.493%、净超额 +0.732%、t 1.513，571 笔。
  - 基线净 PF 0.914、净平均单笔 -0.290%。核心模式仍低于 PF ≥1.15 的验收线 0.025。
- **P0-3 消融：已完成 300 只、320 根的成本后消融与策略组合。** VWAP、量比、实体作为硬过滤会让实际净 PF 从 1.125 降到 0.991；因此 v1.2.0 把它们降为“观察灯”，只保留日线 + 周线 + 可交易性为硬过滤。
- **P0-1 参数扰动：100 只成本后 7 组参数全部保留正超额（100%）**，但这只是 100 只子样本，不足以覆盖全量结果。
- **P0-2 样本去偏：未完成。** BaoStock 历史成分查询本轮被临时限流/黑名单，5 年时点样本没有跑成；不能用当前 300 只冒充 5 年验证。
- **P0-3 Walk-forward：未完成。** 消融和减参数已做，滚动训练/测试仍未做。
- **当前结论**：核心模式先作为默认“候选展示 + 质量排序”，不把 PF 1.125 包装成可交易策略；等 P0-2 / Walk-forward 完成后再决定是否继续收紧。

成本回测与参数扰动报告在 `reports\p0_cost_full_core`、`reports\p0_cost_full`、`reports\p0_ablation`、`reports\p0_cost_smoke`、`reports\p0_cost_perturb`，四方共识在 `reports\four_ai_consensus_v1.2.md`。

## 数据源

| 数据源 | 用途 | 说明 |
|---|---|---|
| 腾讯财经 | 实时快照、日/周/月前复权 K 线 | 主源，速度快；公开接口，无 SLA |
| BaoStock | 历史复权 K 线、指数/ETF、沪深300/中证500 成分 | 深度校验；腾讯 K 线失败时自动兜底 |
| 东方财富 | 备用历史数据 | 当前网络下常不可达，UI 会如实显示 |
| 同花顺 | 涨停原因接口 | 当前只做连通性检测，未进入趋势计算 |
| 本地缓存 | 腾讯日线失败时的短期兜底 | 标记“本地缓存”，不静默冒充实时 |

单票页会做三类校验：

1. K 线最新收盘 vs 腾讯实时快照（同日才比较，阈值 0.5%）。
2. BaoStock 深度校验：后台查一次，最多同步等 2.5 秒；超时先展示腾讯主源结果，后台完成后下次分析显示双源差异。
3. 数据时间戳：K 线截止日期与抓取时间分别展示。

## 数据异常时怎么走

- 腾讯日 K 返回 HTTP 501/429 时，选股先熔断 15 分钟，直接读 `market_data\cache\tencent` 的本地日线缓存；没有缓存才逐只走 BaoStock。
- 单票分析在腾讯 K 线失败时直接改用 BaoStock 前复权；页面上会显示“数据源：BaoStock”。
- 使用缓存时，结果条目和筛选摘要会标“本地缓存（腾讯主源失败）”；缓存数据仍带 `as_of` 日期，不会伪装成当日实时。

## 常见问题

- **打不开 / 白屏**：先看 exe 同级的 `astock_workbench.log`；确认 `_internal` 文件夹和 exe 在一起。窗口默认用 8770 端口，如果被占用会自动顺延。
- **某只股票提示“数据不可用”**：腾讯和 BaoStock 同时失败时会出现。先点“刷新行情”重试；仍失败就在“数据与来源”页看连通状态。东方财富在当前网络下经常不可达，但不影响主流程。
- **选股很久没结果**：沪深300 是逐只拉日线再算指标；正常 1–2 分钟，腾讯 K 线被限流时会先等一轮超时再切缓存，可能更久。页面会显示进度和当前标的。想快一点就用自选池或自定义 5–20 只。
- **收盘后价格不动**：A 股收盘后实时快照停在最后成交，这是正常的；页头会显示行情时间。

## 边界

- 仅个人研究使用，不构成投资建议。
- 不保证行情接口永久可用；接口失效会在“数据与来源”页标红。
- 选股池目前是沪深300/中证500/宽基/自选/自定义，不做 5000+ 全市场逐只扫描。
- 不提供 Level-2、逐笔、资金流、龙虎榜、涨停原因的前端展示。
- 趋势分是规则加权，不是涨跌预测；分数高只说明当前多项技术条件同时成立。
