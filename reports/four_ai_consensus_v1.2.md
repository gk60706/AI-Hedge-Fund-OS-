# 四方评审共识：A股趋势工作台 v1.2.0 该补什么

评审时间：2026-11-23  
参与方：ChatGPT、Hark、Grok、豆包助手  
对象：`market_app` v1.1.0（行情 + 选股 + 来源校验）  
结论：**先补“策略可信度”，暂不扩功能。v1.2.0 定位为“策略可信度增强版”。**

---

## 一、四方一致结论

1. **28.6% 的参数组保留超额，是当前最高优先级问题。** 在成本后、样本外没有证明之前，不再增加 VWAP/Supertrend 以外的新技术因子，不把分钟级信号接入选股主路径。
2. **P0 只做三件事，顺序固定：**
   - P0-1 真实交易成本 + 成交约束进回测
   - P0-2 样本去偏 + 拉长历史 + 固定样本外
   - P0-3 消融 / 减参数 / Walk-forward 稳健性验证
3. **P1 才补使用闭环：** 持仓面板、收盘后提醒、信号台账、财务估值最小集。
4. **P2 再考虑：** 60 分钟/分钟级观察、历史选股复盘、市场环境标签、外部深度点查。
5. **如果 P0-3 仍过不了 70%：停止排名、停止调参；信号类过滤降为“只展示”，可交易性过滤永久保留。** 不再用堆数据源或堆因子的方式抢救。

## 三、P0：先让回测结论可信

### P0-1 成本与成交约束进回测

**解决什么：** 当前超额是毛收益；Top K 是高换手策略，成本可能把超额全部吃掉。

**规则（默认值可配置，不写死）：**

- 成交时点：t 日收盘出信号，t+1 开盘成交。
- 买不到/卖不掉：开盘一字涨停记为买不到；跌停记为卖不掉并顺延；停牌顺延。
- 佣金：万 2.5，最低 5 元。
- 印花税：卖出 0.05%。
- 过户费：0.001%，双边。
- 滑点：单边 0.1%，另跑 0.05%/0.1%/0.2% 三档敏感性。

**验收：**

- 同一回测并排输出“毛 / 净”两套：年化、超额、最大回撤、换手率。
- 单列“未成交信号占比”。
- 成本模型有独立单元测试。
- 成本后超额必须单独报告，不能用毛收益代替。
- 净超额 > 0，才进入 P0-3 的最终判定。

---

### P0-2 样本去偏 + 拉长 + 固定样本外

**解决什么：** 2.3 年不够覆盖牛熊/政策周期；当前成分股回测历史会有幸存者偏差；100 只样本噪声太大。

**怎么做：**

- 用历史时点指数成分，按调整日切换；纳入已退市股票。
- 样本目标 5 年；若历史成分/退市数据拿不到，退到 3 年时点样本，并在报告里明确标注，不宣称长期验证通过。
- 股票池以“可获得的时点成分”为准，不把 800 只当硬指标。
- 先锁定最近 12 个月为样本外，再做任何实验；样本外不反复改参数。
- 输出分年度、分市场环境（上升/下降/震荡）的结果。

**验收：**

- 抽查任意历史日期，当日股票池与当时指数成分一致。
- 退市股在退市前正常参与回测。
- 信号只使用当日收盘后可知字段；成交假设写死为次日开盘。
- 未来函数检查通过；双源冲突日有标记/排除规则。
- 对比“新口径 vs 旧口径”的超额，并记录差额。

---

### P0-3 消融 / 减参数 / Walk-forward

**解决什么：** 28.6% 说明当前超额大概率是参数巧合，或某个过滤器只在个别参数点有效。

**怎么做：**

- 以“只用日线 Supertrend”为基线，逐一加入周线 Supertrend、VWAP20、量比、实体占比、Top K 排序，做消融。
- Supertrend 固定 (10, 3.0)，不再进网格；剩余参数各取 3 档。
- 12 个月训练 / 3 个月测试滚动 Walk-forward；最后 6 个月封存。
- 全部在“成本后”口径下重跑。

**验收：**

- 邻域参数组保留超额比例 ≥ 70%。
- 样本外交易数 ≥ 200。
- 样本外成本后超额 > 0；PF ≥ 1.15；最大回撤不劣于基准。
- 3 个自然年中至少 2 年净超额为正。
- 邻近参数不能断崖式下降。

**兜底：** 仍不过，则 Top K 停止排名、信号类过滤降为展示；可交易性过滤继续保留。UI 明确写“研究候选，不是买入信号”。

## 四、P1：P0 通过后再补使用闭环

1. **持仓组合面板（只读，不下单）**
   - 手工录入：代码、数量、成本、日期。
   - 总市值、浮盈亏、单票权重、行业集中度。
   - 候选股与现有持仓重合提示。
   - 验收：权重合计与总市值一致；能识别单行业集中和单票超限；不接实盘。

2. **收盘后提醒**
   - 每个交易日 15:30 检查：日线 Supertrend 翻空、跌破 VWAP20、触及跌停、自选出现新信号。
   - Windows 通知或邮件二选一。
   - 同一事件只提醒一次；腾讯日 K 501 时照常发出；发前用 BaoStock 交叉校验，避免假警报。

3. **信号台账（P0 规则冻结后第一天开始）**
   - 每日追加：日期、代码、四灯状态、排名、t+1 开盘价。
   - 自动回填 5/10/20 日净收益，对比同期等权基准。
   - 只追加不修改；满 60 个交易日出“实盘跟踪 vs 回测”对比页。

4. **财务估值最小集（只对自选 + Top K）**
   - 字段：PE(TTM)、PB(MRQ)、ROE、营收同比、净利同比、报告期、公告日。
   - 首选 BaoStock；严格按公告日对齐，禁止未来数据。
   - 覆盖率 ≥ 95%；只做“净利为负/ST 风险”可选排除，暂不混入选股评分。

## 五、P2：有余力再做

- **60 分钟/分钟级观察：** 先 60 分钟，15 分钟后续；只用于自选/持仓择时，不进全市场选股主路径；未完成 K 线不触发正式信号。
- **历史选股复盘：** 若 P1 信号台账已经做，复盘直接复用台账，不重复建设。
- **市场环境标签：** 用沪深300/中证500 趋势、波动率、市场宽度划分上升/下降/震荡；第一版只打标签、分组统计，不自动切换参数。
- **外部深度点查（AliceMarket 等）：** 只做单票详情页的手动按钮，不进批量选股；先确认 API Key、免费额度、数据授权和海外可达性。

**明确不做：** 自动下单、分钟级多空信号、全市场财务入湖、多因子研究框架。

---

## 六、助手的补充判断

1. **Hark 的“两类过滤”修正最重要。** 不能因为策略不稳就把 ST、停牌、一字板、上市未满 N 日的过滤也关掉；那是数据卫生，不是 alpha。
2. **5 年不是目的，时点成分才是。** 没有历史成分和退市股，5 年当前成分样本会制造更强的幸存者偏差；这种情况应老实做 3 年时点样本。
3. **信号台账是性价比最高的新增项。** 它不改变策略，只是把每天的 Top K 变成未来可验证的样本外证据；建议 P0 规则冻结后立即开始，不等 P1 其他功能。
4. **v1.2.0 不应增加任何新技术因子。** 先把现有四灯的边际贡献讲清楚；讲不清就降级展示，而不是继续加指标。

---

## 七、建议的下一迭代范围

**v1.2.0 = P0 三项 + 信号台账（只记录，不做提醒）**

- 成本/成交约束回测
- 时点成分 + 退市股 + 5 年/3 年样本审计
- 消融 + 减参数 + Walk-forward
- 每日 Top K 快照落盘（为 P1 台账打底）

P0 验收通过后，再开 P1 持仓、提醒、财务面板。
