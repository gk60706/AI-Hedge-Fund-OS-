# A股趋势工作台 v1.3.0

一个本地优先、个人自用的 A 股行情与趋势分析工具。**不接实盘交易，不生成买卖建议，也不让大模型自由写报告。**

> 仅个人研究使用，不构成投资建议。趋势分是规则加权，不是涨跌预测；分数高只说明当前多项技术条件同时成立。

## 能做什么

- **市场总览**：上证、深证、创业板、科创50 实时快照；自选行情；价格、涨跌幅、成交额、换手率、数据时间。
- **市场雷达 / 情绪**：全市场 6000+ 只 A 股的涨跌家数、涨跌幅中位数、强势/弱势数量、成交额；涨停池与连板梯队、跌停池、炸板池、封板率；龙虎榜。数据日与行情时间都写在页面上。
- **全市场快照筛选**：按代码/名称、板块、涨跌幅、换手率、成交额、总市值、PE、PB 组合筛选，排除 ST，支持排序和条数上限；先批量取快照再筛，不逐只拉 K 线。
- **个股估值与资金面**：PE(TTM)、PB、总市值、流通市值、换手率；近 10 日主力净流入横向条与 5/10/20 日汇总。资金流是平台按成交单大小估算，只观察，不进入趋势评分。
- **个股趋势**：日/周/月前复权 K 线，MA5/10/20/60/120、MACD、RSI、KDJ、BOLL、ATR、量比、20/60/120 日涨幅，叠加 VWAP20 和 Supertrend。
- **信号质量灯组**：日线 Supertrend、周线 Supertrend、20 日 VWAP、量比（前 20 日均量，不含当日）、K 线实体占比。默认核心模式只用日线 + 周线 + 可交易性做硬过滤，其余三盏为观察灯；可切回严格四灯。输出 A/B/C/D 质量分和“新信号/持续合格/未触发/冷却”状态。
- **条件选股**：沪深300、中证500、宽基池、自选池、自定义代码；11 个条件任意组合；可开质量过滤、严格四灯、每日 Top K、同票冷却。
- **今日候选 Top K**：按新信号优先、质量分、命中数、趋势分排序，显示 VWAP 偏离、量比、实体占比和灯组结果。
- **信号台账**：每次带 Top K 的选股完成后，把当日快照写入本地 SQLite；同一天同一只票只记一次，选股页可查看近 30 天记录。
- **数据与来源**：分别检测腾讯实时、腾讯日 K、BaoStock，显示延迟、许可、异常原因；接口失效会标红，不用“看起来可用”代替检测。

## 直接使用打包版

1. 解压 `dist\A股趋势工作台_v1.3.0.zip`（或直接使用 `dist\AStockWorkbench` 文件夹）。
2. 双击 `AStockWorkbench.exe`，会打开独立桌面窗口；不需要 Python、浏览器或数据库。
3. 自选、缓存、信号台账和日志都在 exe 同级的 `market_data` 与 `astock_workbench.log`，整个文件夹可以整体拷走。
4. 首次打开自动加载贵州茅台日线；搜索框输入代码或名称即可切换标的。

> 必须保留 exe 同级的 `_internal` 文件夹，不能只单独拷贝 exe。

## 从源码运行

```powershell
# 依赖见 requirements.txt；推荐使用独立虚拟环境 .venv-market
.\.venv-market\Scripts\python.exe -m uvicorn market_app.server:app --host 127.0.0.1 --port 8770
```

浏览器打开 `http://127.0.0.1:8770`。也可以直接运行桌面入口：

```powershell
.\.venv-market\Scripts\python.exe market_app\launcher.py
```

桌面入口从 8770 端口起自动顺延可用端口。

## 打包 Windows 可执行软件


## 数据源

| 数据源 | 用途 | 说明 |
|---|---|---|
| 腾讯财经 | 实时快照、日/周/月前复权 K 线、全市场批量报价 | 主源，速度快；公开接口，无 SLA |
| 巨潮资讯 | 全 A 代码表 | 市场雷达股票全集，约 6189 只，每天缓存一次 |
| BaoStock | 历史复权 K 线、指数/ETF、沪深300/中证500 成分 | 深度校验；腾讯 K 线失败时兜底 |
| 东方财富 | 涨停池、跌停池、炸板池、龙虎榜、个股日资金流 | 个股快照和板块 clist 在当前网络常被断开；失败会在页面标注 |
| 新浪财经 | 全市场快照兜底 | 腾讯批量失败时启用，覆盖少于巨潮全集 |
| 同花顺 | 涨停原因接口 | 当前只做连通性检测，未进入趋势计算 |
| 本地缓存 | 腾讯日线失败时的短期兜底 | 标记“本地缓存”，不静默冒充实时 |

## 回测与验收进度（v1.2.0 起）

- **P0-1 成本与成交约束：已完成代码与验证。** t 日收盘出信号，t+1 开盘成交；一字涨停买不到、跌停卖不掉顺延、停牌顺延；佣金万 2.5（最低 5 元）、印花税卖出 0.05%、过户费 0.001% 双边、滑点单边 0.1%。
- **当前结果未过验收线。** 300 只当前沪深300成分、320 根缓存（约 1.3 年）成本后回测：核心模式净 PF 1.125、净平均单笔 +0.493%、净超额 +0.732%、t 1.513，571 笔；低于 PF ≥1.15 的验收线 0.025。
- **消融结论**：VWAP、量比、实体作为硬过滤会让净 PF 从 1.125 降到 0.991，因此降为观察灯，只保留日线 + 周线 + 可交易性为硬过滤。
- **P0-2 样本去偏 / Walk-forward：未完成。** 受历史成分数据源限流影响，长样本与时点成分尚未跑成；不能用当前成分冒充长样本验证。
- **当前定位**：核心模式作为“候选展示 + 质量排序”，不包装成可交易策略；等长样本与 Walk-forward 完成后再决定是否收紧。

## 边界

- 仅个人研究使用，不构成投资建议。
- 不保证行情接口永久可用；接口失效会在“数据与来源”页标红。
- 选股池仍是沪深300/中证500/宽基/自选/自定义，逐只拉日线算指标；全市场雷达是另一条快照链路，不逐只拉 K 线，也不把雷达结果直接当作选股信号。
- 不提供 Level-2、逐笔、分钟/tick 行情；资金流是平台估算的“主力净流入”，不是真实机构持仓，只观察，不进入评分。
- 不接实盘交易；不做自动下单。

## 常见问题

- **打不开 / 白屏**：先看 exe 同级的 `astock_workbench.log`；确认 `_internal` 文件夹和 exe 在一起。端口被占用时会自动顺延。
- **某只股票提示“数据不可用”**：腾讯和 BaoStock 同时失败时会出现。点“刷新行情”重试；仍失败就在“数据与来源”页看连通状态。
- **选股很久没结果**：沪深300 逐只拉日线再算指标，正常 1–2 分钟；腾讯 K 线被限流时会先等一轮超时再切缓存。想快一点就用自选池或自定义 5–20 只。
- **收盘后价格不动**：A 股收盘后实时快照停在最后成交，属正常，页头会显示行情时间。
